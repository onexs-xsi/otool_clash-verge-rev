Clash Verge Rev {{APP_VERSION}} - 流量页面版 {{TRAFFIC_VERSION}}（Windows x64，免安装）

启动
1. 请先从系统托盘彻底退出现有 Clash Verge，再双击本文件夹中的 clash-verge.exe。
2. 程序、内核和 resources 必须保留在同一文件夹；移动时请移动整个文件夹。
3. 本版本沿用当前 Windows 用户的 Clash Verge 设置和订阅。沿用 v7–v10 的 SQLite 流量数据库，不清空历史，不导入旧 JSON。
4. 启动时如发现旧版或异常系统服务，会先提示授权更新/修复。当前服务版本为 2.8.1。按 Windows 提示授权后，程序自动重启内核；取消授权可重试，也可仅本次使用用户模式。

保留功能
- 工具栏新增“近期活跃”，根据最近代理网络活动的分布自动划分，至少覆盖 5 分钟，不设固定时长；悬停可看当前参考范围。闲置长连接不会刷新活跃时间；置顶应用保留，其他筛选继续生效。日/月数据仍为完整所选期间的汇总。
- 此筛选用于今日，历史日期显示完整记录，返回今日恢复偏好；跨午夜时，正在查看今日的页面自动跟随新日期。
- Windows 应用识别补齐 IPv4/映射 IPv6、唯一 UDP 套接字与 TUN Fake-IP 场景。同一连接已识别的身份在元数据短暂缺失时保留；不按域名猜应用，也不追溯改写没有证据的旧未知记录。
- Clash / Mihomo 内部连接单独归类。未知应用仍可展开查看实际采集的端点、进程线索、PID 等信息。
- 图标支持按商店安装包的具体 EXE 入口、同一应用的有效父进程回退；成功读取的原生图标在 LocalAppData 缓存，最多 512 个。更新或程序退出后可继续使用；无法取得原生图标时显示名称标识，并明确提示。
- WSL 仍仅运行只读探针，不修改网络、代理、发行版或 TUN 配置。

界面稳定性
- 表格列宽按窗口及可见列分配，长应用名、链路和不断变化的流量数值不会重新挤动其他列。
- 数值单元格预留两行；空间足够时代理值与括号总量并排显示，空间不足时括号换到下一行，行高保持稳定。
- WSL 状态预留宽度，记录路径独立显示；长路径不会挤动控制按钮。展开详情的指标卡和链路表也保持独立、稳定的布局。
- 窗口较窄时可横向滚动表格，或通过“应用”表头的列设置隐藏次要列。完整名称、路径及链路可在展开详情查看。
代理流量统计
- 列表主值、排序、汇总和图表默认只计算经过代理节点的流量。右侧括号显示包含 Direct 的全部流量，例如 100 KB (25.1 MB)。没有额外流量时不显示括号。
- 按链路最终出口判断：DIRECT、REJECT 等不计入代理主值；无法确定出口的记录只计入全部流量，并显示提示。已有历史记录同样采用此口径。
- 默认按当日代理汇总降序排列。“仅看有代理流量的应用”可隐藏当前速度、所选日期和月份都没有代理流量的项目。
- 打开“按应用合并”后，同一应用的多个链路合并成一行。双击展开链路明细；搜索、链路筛选、汇总和图表保持一致。
- 多条代理链路的记录时长可能重叠，合并时显示已知最大时长作为下界，以“≥”标识。Direct 时长不会抬高代理时长。
- 右键应用行可置顶或取消置顶。置顶顺序固定，不参与排序；聚焦展开按钮后也可按 Shift+F10 打开菜单。
- 右键“应用”表头或点击列图标可选择显示列，当月下载和上传默认隐藏。链路支持多选筛选。

平滑流量图
- 橙色区域为上传，蓝色区域为下载，蓝色上边界表示二者总量。两条边界分别平滑拟合并保持顺序，区域直接填充到曲线，消除阶梯顶与平滑线之间的空白。
- 默认使用自适应非线性 Y 轴，以便同时查看尖峰和小流量。可切换对数或线性刻度。刻度模式仅影响显示，采样数值、上传下载在采样点处的比例和 CSV 数值保持原始值。
- 鼠标移动可即时查看时间、上传、下载和合计，定位线会对齐该采样；图表获得焦点后可用左右方向键逐项查看，Esc 关闭提示。
- 默认 1 日视图，支持 1 小时、6 小时、1 日、3 日、1 周、1 月。短时视图聚焦最后有记录的时段；重连补记单独显示，保留完整的 5 秒明细。
- 图表默认只显示代理流量。打开图内“包含 Direct”可检查全部流量；纯 Direct 应用没有代理曲线时也可一键查看全部。
- 1 日内按 5 秒汇总，3 日按 3 小时，1 周及 1 月按日统计。无法定位时间的断流、休眠补记单独列出并计入汇总，不合并该小时已有的 5 秒明细。缺少采样的时段保持断开。

导出与记录管理
- “导出 CSV”保存当前筛选、排序后的全部结果，包含置顶及所有分页。代理与全部流量分列保存，流量单位为字节、速度为字节/秒，便于 Excel 进一步计算。
- 展开“未知应用”可查看所选日期新采样的目标地址、来源、协议、识别结果，以及当前 WSL 探针状态。每条链路每天保留最近 32 条诊断，最多显示 100 条；当前 WSL 状态不能证明历史连接来自 WSL。
- 可清空所选日期或全部记录，诊断也会一并删除。流量和诊断保存在当前用户的 %APPDATA%\io.github.clash-verge-rev.clash-verge-rev\traffic\history.sqlite3，实际路径显示在流量页面。

WSL 监测
- 流量页和设置页均有监测开关。TUN 关闭时会先询问是否开启，TUN 已开启时直接监测；关闭 WSL 监测不会自动关闭 TUN。
- WSL 尚未运行时显示等待提示；程序不会主动启动 WSL。使用只读探针读取 WSL 进程及 Windows NAT 会话，不修改 WSL 的网络或代理配置。
- 发行版需要 python3、ss 和 ip；NAT 关联需要 Windows 可读取 Get-NetNatSession。只识别已进入 Clash 且能够关联的连接，极短连接和部分 UDP 等仍可能无法识别。

注意
- 流量是连接采样估算。未知应用的旧记录无法补出目标地址或可靠重新归类。
- 请勿与旧版同时运行；v6 使用原来的 JSON，与 v7 数据库独立。v8 继续使用 v7 的 SQLite 记录；可在“记录管理”中创建备份。
- 本程序为自编译、未签名的免安装版本，系统可能显示来源提示。

SQLite 与连续记录
- 数据库位于 %APPDATA%\io.github.clash-verge-rev.clash-verge-rev\traffic\history.sqlite3，结构化保存日、小时和 5 秒数据。诊断的扩展信息保存在独立记录中。
- 使用 WAL、完整同步和事务提交；连接计数检查点与流量一同提交，恢复时避免重复累计。约每 5 秒提交变化，正常退出时尽量完成最后落盘。
- 内存仅保留当前日期及最近时间格，历史按查询范围从数据库读取。默认不自动删除记录，可清空所选日期或全部记录。
- “记录管理”中的“备份数据库”创建一致的 SQLite 备份。运行中可能存在 -wal 和 -shm 文件，不要只复制主文件来代替备份。
- 窗口关闭但仍驻留托盘时继续记录；彻底退出则停止。重启后可以恢复仍存活连接的可核对差额，退出期间已经结束的短连接无法补齐。

图标与识别信息
- 尝试 EXE 资源、商店应用标识、运行窗口、系统 Shell 以及同一应用目录中的父程序图标；缺少路径时尝试当前进程和注册的程序路径。失败缓存每分钟重试，最多四个并发提取。
- 本身没有图标、路径失效或权限受限的程序仍可能显示通用图标；不会用不相关的启动器图标冒充应用。
- 展开应用后可查看当前进程名和 PID；“进程信息”列出完整路径、父进程与匹配方式。同名结果仅为候选，不证明历史连接归属。
- 未知应用的识别信息显示采样证据、当前连接匹配的进程、PID、来源端口、目标与原因，并支持重新检测和复制识别信息。

本次迭代
- 同一安装应用更新版本后自动合并记录、链路明细与图表，原有置顶延续；展开后可查看各版本路径和当前进程。不同安装目录、不同软件包发布者仍分别统计。
- 休眠或长时间采样中断后，将可核对的累计计数差额列入“时间未定位的补记”，保持已有 5 秒明细。短暂重连在已知短采样间隔内继续细粒度记录。
- 记录管理提供数据库/WAL 占用、记录日期、5 秒明细数、最近保存时间、完整性检查、在线备份和空间回收。空间回收保留已有历史。
- 图表按屏幕像素精简不可见的顶点，保留上下边界峰谷与原始 5 秒悬停数据；短暂刷新失败时保留上次曲线，可手动刷新。
- 历史查询只读取所需数据；三日视图不读取 5 秒明细，诊断不读取图表数据。读取与写入整理保持顺序，避免中途落盘导致视图漏掉明细。
